# HANDOFF: короткий старт

Этот файл специально короткий. В новом чате читать его можно, но лучше начинать с `START.md`.

## Что читать

1. `START.md` - актуальный контекст проекта, читать всегда.
2. `AGENTS.md` - правила работы Codex в репозитории.
3. `DECISIONS.md` - устойчивые UX/архитектурные решения, читать при спорных правках.
4. `TODO.md` - ближайшие задачи.
5. `HISTORY.md` - длинная история изменений, читать только если реально нужен старый контекст.

## Быстрый старт для нового чата

> Продолжай проект `finance-tracker-mvp-2`. Прочитай только `START.md`. `HISTORY.md` не читай без необходимости.

## Правило поддержки контекста

- `START.md` держать коротким: только текущее состояние, риски, команды проверки и ближайшие задачи.
- `HISTORY.md` не дописывать каждую мелочь; переносить туда только крупные вехи.
- `DECISIONS.md` обновлять, когда принято решение, которое важно не откатить.
- После логически завершенного этапа делать git-коммит.
