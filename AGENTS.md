# AGENTS.md

Правила для Codex в этом репозитории.

## Старт нового чата

1. Сначала прочитай только `START.md`.
2. Выполни `git status --short --branch`.
3. Читай только файлы, нужные для текущей задачи.
4. `HISTORY.md` не читать без явной необходимости.

## Стиль работы

- Отвечай пользователю коротко и по делу, на "ты".
- Пользователь не программист; объясняй результат простыми словами.
- Не делай лендинг вместо приложения.
- Не трогай несвязанные файлы.
- Не переписывай архитектуру без причины.
- Не удаляй эмоджи из UI без прямой просьбы.

## Проверки

После JS-правок обязательно:

```bash
node --check app.js
```

После UI-правок:

- открыть локальный `index.html` в in-app browser;
- проверить console errors;
- проверить измененный пользовательский сценарий.

## Контекст

- `START.md` держать коротким.
- `DECISIONS.md` обновлять только при важных продуктовых/технических решениях.
- `TODO.md` обновлять при смене ближайших задач.
- `HISTORY.md` использовать как архив, не как стартовый контекст.

## Git

- Один завершенный этап - один осмысленный commit.
- Перед commit проверить `git status`.
- `.DS_Store`, временные файлы, секреты и `.env` не коммитить.
