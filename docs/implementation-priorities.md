# Implementation priorities

## Сейчас: первая рабочая версия

Цель: получить цельный MVP, которым можно пользоваться вручную.

Обязательно:

- главный дашборд с доходами, расходами и остатком;
- рабочие операции: доход / расход / перевод;
- счета;
- категории и подкатегории;
- теги;
- добавление и редактирование операций;
- список операций с группировкой по дням;
- фильтры по дате, счету, категории, тегам и сумме;
- базовые отчеты: бублик и динамика;
- настройки;
- светлая/темная/автоматическая тема;
- экспорт и импорт данных;
- бюджеты;
- цели.

## Следующий слой

После первой рабочей версии:

- Supabase Auth;
- сохранение данных в Supabase;
- синхронизация между устройствами;
- RLS-политики;
- PWA;
- улучшение импорта банковских выписок;
- расширенная аналитика;
- сравнение периодов;
- тренды расходов.

## Технические решения

Пока локально:

- статический MVP без npm;
- данные временно в localStorage;
- старый Supabase не используется.

Дальше:

- подключить новый Supabase-проект;
- завести таблицы accounts, categories, tags, operations, budgets, goals;
- добавить авторизацию;
- вынести хранение из localStorage в Supabase;
- оставить экспорт/импорт как страховку.

## Ближайшие правки к текущему MVP

1. Упростить визуальный стиль: меньше декоративности, больше чистого Apple-like пространства.
2. Переделать верхнюю навигацию под разделы: Главная, Операции, Отчеты, Планы, Настройки.
3. Добавить счета и переводы между счетами.
4. Добавить категории, подкатегории и теги как реальные сущности.
5. Переделать форму операции под доход / расход / перевод.
6. Добавить редактирование и дублирование операций.
7. Добавить дневные группы в списке операций.
8. Улучшить график планов: интерактивный выбор дня, tooltip, красная зона нехватки денег.
9. Улучшить отчет-бублик: категории, иконки, emoji, проценты.
10. Подготовить структуру под Supabase.
